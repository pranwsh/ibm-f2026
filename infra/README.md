# Infrastructure

The local stack is defined in [`docker-compose.yml`](docker-compose.yml). For service addresses, startup, and the slim profile, see [Services](../docs/services.md). Kafka topic setup is documented in [Kafka topics](../docs/kafka-topics.md).

Postgres and ClickHouse initialization files are in their respective subdirectories. Kafka topic initialization is in `kafka/init-topics.sh`.
